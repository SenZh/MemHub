## 3. 使用与验证指引

### 3.1 WebUI 界面操作
1. 打开浏览器访问 `http://127.0.0.1:3900`；
2. 在「知识全景」或「检索实验」中点击任意需要清理的卡片，弹出 L2 详情抽屉；
3. 点击底部左侧的「🗑️ 删除记忆」按钮；
4. 在确认框中核对卡片标题与 ID，点击“确定”；
5. 系统弹出成功 Toast，该卡片即刻从页面和数据库中彻底抹除。

### 3.2 CLI 终端命令操作
```bash
# 交互式确认删除
memhub delete kb-xxxx

# 静默免确认删除（适用于脚本自动化）
memhub delete kb-xxxx --yes
# 或别名:
memhub rm kb-xxxx -y
```

### 3.3 自动化测试回归
```bash
# 运行删除功能专项测试
node tests/test-deletion.js

# 运行全量 15 套件自动化验证
node tests/e2e.js
```
