# 产出契约 (Contract) (修订版 v2)

| 场景 | 完成标准（可证伪） | 验证方式 |
| :--- | :--- | :--- |
| **主路径 1：CLI 命令规范** | 执行 `package.json` 中的 `bin` 映射，`memhub` 与 `mem-hub` 可正常输出帮助；`memory-hub` 作为 MCP 入口可调通；彻底不再包含 `hub` 命令。 | `node src/cli.js` 输出，读取 `package.json` 校验 `bin`。 |
| **主路径 2：动态静默阈值过滤** | 当配置或传参 `idleMinutes: 30` 时，仅有更新时间在 `now - 30分钟` 以前的会话被召回；更新时间在 10 分钟前的热会话 100% 返回空列表。 | 编写集成测试，模拟不同时间戳的会话记录。 |
| **主路径 3：目录 Exclude 黑名单过滤** | 当会话路径匹配 `exclude` 数组（例如 `**/tmp-test/**`）时，该会话必须返回 `false` 并被 100% 拦截剔除，哪怕它同时满足 `include`。 | 单元测试，传入带黑名单路径断言返回 `false`。 |
| **主路径 4：目录 Include 白名单过滤** | 当设置了 `include` 规则时，只有命中了 include 模式的路径返回 `true`，未包含的目录返回 `false`。 | 单元测试，传入非包含路径断言返回 `false`。 |
| **主路径 5：WatchDirectories 根目录限制** | 当设置了 `watchDirectories: ["D:/workspace/projects"]` 时，位于其他磁盘或外部目录（如 `D:/temp/test`）的会话返回 `false`。 | 单元测试，传入根目录外路径断言返回 `false`。 |
| **主路径 6：自循环萃取安全防卫** | 标题包含 `[MemHub]` 前缀的会话在 SQL 查询中被强制过滤，不返回到候选集。 | 构造包含 `[MemHub]` 标题的会话，断言扫描结果中不包含该 ID。 |
| **边界与异常：特殊正则字符与盘符转义** | 路径中包含 `.`（如 `node.js`、`v0.2.1`）、`+`、`(` 等特殊符号，编译后正则正常运行，绝不抛出语法错误或导致意外通配。 | 单元测试构造含特殊字符路径验证匹配准确性。 |
| **边界与异常：空路径与非法时间值** | 会话 `directory` 为 `null`/`undefined` 时返回 `false`；配置传入非法时间（如 `"abc"`、`-5`）时，自动回退到默认 120 分钟。 | 单元测试传入极端值验证安全回退。 |
| **相邻影响：向后兼容性** | 兼容现有的 `exo` 命令调用与 `EXOBRAIN_HOME` 环境变量。 | 运行旧测试套件全部保持通过。 |
